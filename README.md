# Vault Gallery — Pattern Lock Media Gallery

A browser-based media gallery with a pattern-lock interface, built using HTML, CSS, and JavaScript.

🔗 **Live Demo:** https://ALIRAZA123-AV-IS-available.github.io/vault-gallery/

📂 **Source Code:** https://github.com/ALIRAZA123-AV-IS-available/vault-gallery

## About the Project

Vault Gallery is a front-end web application that lets users access a personal image and video gallery through a pattern-based interface. It demonstrates responsive UI design, browser-based media storage, and interactive JavaScript functionality.

## Features

- **Pattern Lock:** Access the gallery through a pattern-based interface.
- **Multiple Lock Styles:** Choose from supported pattern and grid styles.
- **Image and Video Gallery:** Upload and view supported media files.
- **Browser Storage:** Uses IndexedDB to store media locally in the browser.
- **Search and Sorting:** Find and organize gallery items.
- **Gallery Controls:** Includes supported options such as favorites, view modes, renaming, and downloads.
- **Themes:** Dark and light appearance options.
- **Responsive Design:** Designed for different screen sizes.
- **Privacy Information:** Explains the limitations of browser-based storage and the pattern lock.

## Technologies Used

## How to Use

1. Open the [Live Demo](https://ALIRAZA123-AV-IS-available.github.io/vault-gallery/).
2. Complete the initial setup and create a pattern.
3. Unlock the gallery using your pattern.
4. Upload supported images or videos.
5. Use the available search, sorting, gallery, and settings options.

## Storage and Security Notes

Media is stored in the browser on the device and browser profile being used. It is not automatically uploaded to a cloud server or synchronized across devices.

**Important:** The pattern lock is an interface-level privacy feature, not strong authentication. Media is not encrypted by this application, so this project should not be used to protect highly sensitive files.

Clearing browser data or losing access to the browser profile may affect access to locally stored media.
