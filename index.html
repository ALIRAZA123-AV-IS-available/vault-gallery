Backup & restore

Export your whole library (original files, albums, favourites, Trash and preferences) as ZIP files that you keep yourself. Your lock sequence is not included: after restoring on a clean browser, set a new sequence first, then restore here.

About the backup format

Each backup part is a normal ZIP file containing manifest.json (version, albums, preferences, one record per file with checksums) and the original files under media/. Large libraries are split into parts; select all parts when restoring. Restoring never overwrites existing files: duplicates are skipped or kept as extra copies, as you choose.

Security & privacy

  • This is a front-end privacy lock. It is not real authentication: anyone who can use this browser profile or open its developer tools can reach the stored files.
  • Media is not encrypted. A 4–9 tile sequence has too few possible combinations to protect an encryption key, so claiming encryption would be misleading. Backup ZIP files are also not encrypted: store them somewhere private.
  • Nothing is uploaded anywhere. Cross-device access or real accounts would need a backend with authentication, authorization and server-side storage.

Reset

Resetting preferences restores theme, lock style, view, auto-lock and Trash period to defaults. It does not touch your sequence, albums or media.
